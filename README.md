# Sistema de Control de Laboratorios de Cómputo (Móvil) - Proyecto C

Aplicación Móvil Nativa desarrollada con **React Native + Expo** para la gestión y asignación de equipos de cómputo y periféricos en los laboratorios de la Universidad Tecnológica El Retoño (UTR).

## Variables de Entorno
Copia el archivo `.env.example` a `.env` y configura las credenciales correspondientes:
- `EXPO_PUBLIC_API_URL`: URL base de la API RESTful.
- `EXPO_PUBLIC_API_APP_TOKEN`: Token de autenticación de la aplicación cliente (`x-api-token`).

## Instalación y Ejecución Local
```bash
npm install
npx expo start
